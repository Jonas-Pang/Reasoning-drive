3 · What the car does (optional)

Sampling
Upload a dash-cam or simulator clip.
The system takes frames from it, reads the two lines of the lane in each frame, applies the chosen rules, merges frames with the same lines into segments and shows what the car may do along the clip.
With a navigation intent it checks the intended manoeuvre at the end of the clip; with an event file it checks every executed manoeuvre and, if the file gives the ground truth, says whether perception or decision was at fault.

Use your own API key

How your key is handled

  1. It is sent once to this service and kept in its memory only, for this browser tab.
  2. It is never written to a file, the prediction log, the metrics or the results; the page shows only its last 4 characters.
  3. Requests go from this service straight to the provider you chose; the costs go to your account.
  4. It is forgotten when you press Forget my key or the service stops.

After you press “Use this key”

The Model lists on Analyze and Video get “Your key · model”, already selected. Upload your own photo or video and press Analyze. Test-set photos only take a model whose prompt and settings were frozen for the test (the evaluation rule); use an upload with a new model.

Where to get a key

OpenAI: platform.openai.com → API keys. UF NaviGator: Virtual Keys → Create New Key, with Team = navigator-toolkit (otherwise 401). Other: any service with an OpenAI-style /chat/completions that accepts images and JSON-schema answers.

“Check key” only asks the provider’s free model list (/models); it uses no tokens.

How feedback is used

  1. Logged to results/app/feedback.csv and counted in Prometheus (app_feedback_*).
  2. Analysed weekly: wrong-rate per action and region (frequency) and comment themes (e.g. solid vs dashed, bus lanes) — scripts/feedback_report.py.
  3. Triaged: answers marked wrong go to the label-review queue; a confirmed error becomes a test case.
  4. Acted on: a recurring theme changes the prompt (v3 → v4 → v4c came from this loop) or the rule table, then the frozen test set is re-run before release.
